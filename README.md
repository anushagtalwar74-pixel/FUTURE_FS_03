# ☕ Brew Haven Cafe

A premium, responsive, and modern café website built as a real-world business project for **Future Interns – Full Stack Web Development Task 3 (2026).**

---

# 📌 Project Overview

**Brew Haven Cafe** is a professional café website designed to help a local café establish a strong online presence.

The website provides customers with:

- Modern Homepage
- About Us
- Digital Menu
- Gallery
- Online Table Reservation
- Contact Information
- Google Maps
- Newsletter Subscription
- Mobile Responsive Design

---

# 🎯 Objective

The purpose of this project is to demonstrate how a professionally designed website can help a real café business:

- Increase customer trust
- Improve online visibility
- Display menus digitally
- Accept reservation requests
- Showcase products
- Build a professional brand image
